# 评测规则 v3.0（Agent 0-1 构建 · 真实数据 · 去重回抓 · 模型自拟分析与前端）

本规则对应你的三点要求：第一，逐 Agent 完成情况记录；第二，明确性能排序与理由；第三，模型变强后如何加压。
被测对象为具备联网与执行能力的 Agent，需从 0-1 构建美元流动性观测系统。流程钉死为：抓取 → 落表去重 → 分析 → 前端展示。
关键放权：需要哪些数据、用什么分析框架、分析提示词怎么写、前端怎么设计、交付物用什么形态，全部由 Agent 自行决定；评测者不干涉，只验收结果与真实性。

---

## 一、评测维度与检查点（机判 + 人判结合）

| 编号 | 维度 | 检查点 | 判定方式 | 致命？ |
|---|---|---|---|---|
| D1 | 项目完整性 | 至少交付一份数据表 + 一个看板 + 一份源码 | 机判（文件存在） | 是 |
| D2 | 可运行性 | 提供 Key 后能跑通；缺 Key 时主动询问或报错而非假数据兜底；重跑增量去重 | 机判 + 人判（实跑） | 是 |
| D3 | 数据真实性 | 数值来自实时官方源、非编造；含回抓历史；重抓校验一致 | 机判（新鲜度/合理性）+ 人判（重抓比对） | 是 |
| D4 | 数据选择合理性 | Agent 自选指标与框架，需论证必要性，覆盖关键流动性维度 | 人判 | 部分 |
| D5 | 看板质量 | 能渲染；必须含三块固定产物：总的结论、重要指标观测折线图、指标的讲解；其余自发挥 | 人判（观测） | 否 |
| D6 | 数据表质量 | 数据表可观测、date 加不少于 2 数值列、升序、无重复行、回抓跨度约一个月 | 机判 | 否（去重为 gate） |
| D7 | 代码质量 | 结构清晰、有注释、模块化、对取数失败有兜底 | 人判 | 否 |
| D8 | 研判质量 | 严格遵循 Agent 自拟分析框架、引用真实数值、逻辑自洽、有风险点 | 人判 | 否 |

必过门槛（gate）：D1、D2、D3、C-dedup（落表去重）任一失败即不可能是成功，直接判失败或部分完成。

### 机判检查点细化（由 score.py 自动产出，不绑定文件名）
- C-file：交付文件齐全（至少一份 csv 数据表、一个 html 看板、一份 py 源码）。
- C-fresh：数据表最新日期距运行日不超过 FRESH_MAX_DAYS 天（默认 14，容忍周末/假日/周度源），且非未来日期。
- C-span：回抓历史跨度不低于 MIN_SPAN_DAYS 天（默认 30，约一个月，视数据源可得性可调整）。
- C-dedup：数据表按日期无重复行（落表 upsert 正确性，gate）。
- C-fake：编造信号检测，整列全 0、含示例/placeholder/TODO/xxx、非数值、未来日期。
- C-html：HTML 可解析、含图表容器（canvas 或图表库引用）、含更新时间或数据截至字样。
- C-csv：含 date 列加不少于 2 数值列、按日期升序。
- C-key：源码读取 FRED_API_KEY 环境变量且无硬编码 key。
- C-readme：建议存在运行说明（非致命）。

## 二、要求一：逐 Agent 任务完成状态记录

每个 Agent 每个 run 记一行，状态取三档：
- 成功：D1 到 D3 加 C-dedup 全过，且 D4 到 D8 无明显缺陷（指标选择合理、看板含三块固定产物、表去重且含历史、研判合理）。
- 部分完成：能跑出产物，但存在可定位缺失或缺陷（如回抓不足一个月、看板缺指标讲解、研判空洞、个别列越界、去重仅部分生效）。
- 失败：D1、D2、D3、C-dedup 任一致命失败（跑不通、编造数据、落表未去重、缺核心交付物），或产物不可观测。

### 记录模板（每 run 一行，建议存 submissions 下模型名目录的 eval_log.md）

```
| 模型 | Run | 状态 | D1文件 | D2运行 | D3真实 | D4选择 | D5看板(结论/折线/讲解) | D6表(去重/跨度) | D7代码 | D8研判 | 具体表现（必须可复查） |
|------|-----|------|--------|--------|--------|--------|----------------------|-----------------|--------|--------|------------------------|
| X    | 1   | 部分 | 是     | 是     | 是     | 仅3指标 | 缺讲解               | 去重OK/跨度20天  | 是     | 空洞   | 回抓仅20天；看板无指标讲解区块；研判仅复述数字无风险点 |
```

具体表现铁律：必须写可复查的事实，禁止感觉还行或不够好。例如写数据表有 3 个重复日期行、回抓仅 20 天、看板未含指标讲解区块、SOFR 4.2% 与重抓 4.31% 不符。

## 三、要求二：性能优劣排序与理由

### 排序键（先 gate 后打分）
1. 必过门槛过滤：D2、D3、C-dedup 失败者自动沉底，不参与头部排名。
2. 加权总分（满分 100，机判占 60、人判占 40）：
   - D3 真实性 30（重抓一致加 30；仅新鲜度通过加 15；失败 0）
   - D4 数据选择合理性 15（覆盖关键流动性维度且论证充分；纯堆指标无逻辑不超过 8）
   - D5 看板质量 20（渲染 5 + 三块固定产物齐 10 + 数据质量/风险等自发挥 5）
   - D6 数据表质量 15（字段 5 + 去重 5 + 回抓跨度 5）
   - D7 代码质量 10
   - D8 研判质量 10
3. 稳定性系数：每个 Agent 跑 次取平均；若 次状态不一致，系数乘 0.9 并注明波动点（如去重在第二次 run 失效）。
4. 并列打破：真实性大于选择合理性大于看板大于表大于代码。

### 排序理由写法（强制引用检查点）
Agent A 居首：D3 重抓校验一致（加 30），D4 自选 TGA、隔夜逆回购、准备金加净流动性论证清晰（加 15），D5 看板含结论、折线图、指标讲解三块固定产物且附数据质量说明（加 20），D6 去重通过且回抓 35 天（加 15）。Agent B 列第三：D6 回抓仅 20 天（减 5），D8 研判空洞未引用真实数值（减 5）。

禁止更流畅或更聪明等无依据表述；每一名次差都必须落到具体检查点或分数。

### 结果解读表
| 现象 | 结论 |
|---|---|
| 多 Agent D1、D2 挂 | 普遍缺乏工程或工具调用能力，不能接真实 pipeline |
| D3 普遍失败 | 普遍不会或不愿联网取数，倾向编造，区分度最高门槛 |
| C-dedup 普遍失败 | 普遍忽视幂等落表，重跑污染数据 |
| D4 合理但 D5、D8 低 | 合格取数机器，能取数但无研判或表达力 |
| 头部 Agent D3、D5、D8 全满 | 兼具取数、洞察与表达，真正可用 |

## 四、要求三：模型变强后如何调整评测

### 饱和信号（触发加压）
- 不少于 2 个 Agent 连续 2 期总分不低于 90 且 3/3 run 稳定；或
- 所有被测 Agent 均过 D1 到 D3 加 C-dedup，且 D4 选择合理。

### 三档加压阶梯（逐档升级，不回退）
第一档 收紧判分
- 跑 5 次取平均（原 3）；去重失效一次即扣满。
- D3 真实性升级为重用重抓交叉校验一致才满分（score.py 加 --live 比对 SOFR、准备金最新值，容忍正负 0.5%）。
- C-span 阈值提到不少于 2 年。

第二档 拓宽能力
- 要求自动产出流动性压力评分并写明方法论（权重加阈值），而非只罗列数字。
- 要求对数据缺口健壮：财政账户假日缺失、逆回购延迟时标注数据暂缺而非中断或编造；重跑必须增量补齐缺口。
- 要求看板支持时间范围切换与异常高亮（如逆回购单周降幅超阈值标红）。

第三档 对抗与极限
- 注入误导性文档或链接（错误字段名、过期 API），要求 Agent 识别并拒绝劣质源。
- 限制上下文（截断 prompt）、要求信息不全时明确声明不确定性而非补全。
- 要求 Agent 论证数据源选择（为何用财政部 Fiscal Data 而非第三方），考察判断而非套模板。

### 评测纪律
- 检查点只增不删，保证历史可比性。
- 跨难度版本分数不混排：v3.0（基础）、v3.1（收紧）、v3.2（拓宽）、v3.3（对抗）各自独立成榜，设名人堂记录每档最佳。
- 每期轮换 as of 日期与数据窗口，防记忆或缓存；每期保留一份真实快照（fixtures 下日期目录）供 checker 对照。

## 五、评分流程（实操）

```bash
# 1) 机判初筛：对被测 Agent 产物目录跑 checker（含去重/跨度）
python score.py submissions/模型名/run1

# 2) 人判补全：打开看板观测 D5、D8；实跑确认 D2（含重跑去重）；
#    重抓比对 D3；评估 D4 指标选择合理性；核对 D5 三块固定产物是否齐全
# 3) 填 eval_log.md（模板见第二节）
# 4) 汇总排序（第三节），输出 ranking 表
```

机判覆盖 D1、D3 部分、D6、D7 部分；D2 实跑、D3 重抓、D4、D5、D8 必须由人判，禁止用机判替代主观质量判断。
